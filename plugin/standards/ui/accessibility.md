# WCAG 2.2 AA

* User interfaces MUST target WCAG 2.2 Level AA.
* Interfaces MUST support keyboard navigation, appropriate focus states, semantic HTML, accessible
  forms, readable content, sufficient contrast, and screen-reader compatibility.
* Accessibility MUST NOT be treated as an optional enhancement.
