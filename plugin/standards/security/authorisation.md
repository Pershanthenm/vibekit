# Authentication & authorisation

* Authentication MUST verify the identity of the caller.
* Authorisation MUST verify whether the caller is permitted to perform the requested operation.
* Security checks MUST be enforced server-side.
* Client-side UI restrictions MUST NOT be considered a security boundary.
* Permissions MUST follow the project's selected identity and access-control architecture.
