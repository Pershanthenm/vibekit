# Secure dependency management

* Dependencies MUST be deliberately selected and kept to a minimum.
* Unnecessary packages MUST NOT be introduced.
* Dependencies SHOULD be kept reasonably up to date.
* Known critical security vulnerabilities MUST be addressed before release.
* A library MUST NOT be introduced simply because it makes implementation easier when existing
  project capabilities are sufficient.
