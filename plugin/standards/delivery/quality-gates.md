# Quality & security gates

* Code MUST pass the project's defined quality gates before being considered complete.
* Gates SHOULD include, where applicable: build/compilation, unit tests, integration tests, code
  analysis, security scanning, dependency vulnerability scanning, secret scanning, code coverage,
  accessibility validation, and formatting/linting.
* A feature MUST NOT be considered complete simply because the application runs successfully.
