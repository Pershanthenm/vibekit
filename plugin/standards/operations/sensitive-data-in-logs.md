# No sensitive information in logs

* Passwords MUST NEVER be logged.
* Access tokens, refresh tokens, API keys, secrets, private keys and credentials MUST NEVER be logged.
* Sensitive personal or customer information MUST NOT be logged unnecessarily.
* Request/response logging MUST be carefully controlled for sensitive endpoints.
