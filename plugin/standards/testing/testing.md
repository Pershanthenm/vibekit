# Testing

* Code MUST be appropriately tested based on its risk and purpose.
* Business logic MUST have automated tests where appropriate.
* APIs MUST have appropriate integration/endpoint tests.
* Authentication and authorisation paths MUST be tested.
* Critical workflows MUST have regression coverage.
* Bug fixes SHOULD include tests that prevent the issue from recurring.
* Generated code MUST NOT be considered complete merely because it compiles.
